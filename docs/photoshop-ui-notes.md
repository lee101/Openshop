# Photoshop UI Notes

These notes capture workspace conventions to guide OpenShop's visual work.

## Official Sources

- Photoshop workspace overview: https://helpx.adobe.com/photoshop/desktop/get-started/learn-the-basics/workspace-overview.html
- Photoshop keyboard shortcuts view: https://helpx.adobe.com/ca/photoshop/desktop/get-started/settings-and-preferences/view-keyboard-shortcuts.html

## Workspace Pattern

- Top application/menu area for file/edit/image/layer/select/filter/view/window/help style commands.
- Tool options bar directly below the menu, changing with the selected tool.
- Left vertical tools panel with compact icon buttons.
- Center document window on a neutral dark pasteboard.
- Right stacked panels for color, properties, layers, history, and adjustments.
- Contextual controls should appear near the document only when they are directly relevant.

## OpenShop UI Priorities

- Keep controls compact and professional: small icon targets, visible active states, dense panels, restrained colors.
- Every tool needs a visualbench screen with the active toolbar button, representative marks on the document, and right panel state.
- Avoid feature explanation text inside the app shell. Use visual affordances, icons, panel structure, and shortcuts.
- Add a shortcut editor once enough commands exist to justify user customization.
