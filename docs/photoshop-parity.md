# Photoshop Parity Plan

OpenShop is a plain C image editor with a JavaScript command facade. This file tracks the practical Photoshop-alternative target without copying Adobe documentation into the repo.

## Current Foundation

- Plain C canvas, layer stack, brush, eraser, line, rectangle, filled rectangle, ellipse, filled ellipse, fill, eyedropper, transforms, layer opacity, lock, visibility, merge, and history.
- SDL desktop shell with a compact Photoshop-style workspace: menu strip, options bar, left tools, center document, right panels, and bottom status/options area.
- C API in `src/openshop_api.h` and matching JavaScript facade in `js/openshop-api.mjs`.
- Visual QA screenshots generated by `make visualbench` into gitignored `visualbench/`.

## Feature Parity Targets

- Selection tools: rectangular marquee, lasso, magic wand, selection feathering, select all, deselect, invert selection.
- Navigation tools: move tool, zoom tool, hand/pan tool, fit to screen, actual pixels.
- Brush system: pressure-ready brush model, hardness, spacing, blend modes, brush presets, custom tips.
- Pixel editing: crop, resize canvas, image resize, clone stamp, healing, blur, sharpen, smudge, dodge, burn, sponge.
- Layers: groups, masks, clipping masks, blend modes, adjustment layers, smart-object-like embedded documents.
- Text and vectors: editable text layers, path editing, vector shapes, stroke/fill properties.
- Color: foreground/background swatches, swap/default colors, color picker, gradients, pattern fill.
- Files: PSD import/export strategy, PNG/JPEG/BMP/TIFF baseline, autosave/recovery, recent files.
- Automation: stable C command ABI, JavaScript command facade, batch command execution, scriptable document/layer/tool state.
- UI: keyboard shortcut editor, contextual options bar, panel docking, compact property panels, visualbench coverage for every tool and panel state.

## Visual Bench Checklist

Run `make visualbench` after UI work. Inspect at least these outputs:

- `visualbench/editor-overview.bmp`
- `visualbench/layer-states.bmp`
- `visualbench/tools-gallery.bmp`
- `visualbench/tool-brush.bmp`
- `visualbench/tool-eraser.bmp`
- `visualbench/tool-line.bmp`
- `visualbench/tool-rectangle.bmp`
- `visualbench/tool-ellipse.bmp`
- `visualbench/tool-fill.bmp`

The screenshots should stay dense, readable, and familiar to Photoshop users: left tool rail, central document, top options, right properties/layers/color panels, and no decorative landing-page UI.
