# Photoshop Parity Plan

OpenShop is a plain C image editor with a JavaScript command facade. This file tracks the practical Photoshop-alternative target without copying Adobe documentation into the repo.

## Current Foundation

- Plain C canvas, layer stack, brush, eraser, line, rectangle, filled rectangle, ellipse, filled ellipse, fill, eyedropper, transforms, layer opacity, lock, visibility, merge, and history.
- 14 layer blend modes (`src/blend.h`) honored by compositing and merge down; `Shift+=`/`Shift+-` cycle the active layer mode.
- Image adjustments and filters (`src/adjust.h`): brightness/contrast, hue/saturation/lightness, levels, desaturate, posterize, threshold, gaussian blur, sharpen.
- Deterministic VFX brush engine (`src/brush_engine.h`): soft round, airbrush, splatter, glow, sparkle, smoke presets with hardness, flow, spacing, scatter, size jitter, additive blending.
- Photoshop-style JS DOM facade (`js/photoshop-api.mjs`): `app`, `documents`, `artLayers`, `activeLayer`, `BlendMode`, layer adjustment methods, and a minimal `batchPlay`.
- Compact mode: `Tab` hides panels; `app_layout_compact()` is the tested layout variant.
- Selections (`src/selection.h`): rect marquee, ellipse, magic wand, select all/deselect/invert, add/subtract ops, feather, masked editing of every paint/adjust op, marching ants in the shell (`M`/`W` tools).
- Gradient fills (`src/gradient.h`): linear and radial, selection-aware.
- Crop, image resize (bilinear), canvas resize with anchor offsets across the layer stack.
- PSD: flattened export, raw + RLE composite import (`src/psd.h`).
- Layer masks (from selection or reveal-all, enable/disable, apply/discard) and clipping masks, honored by compositing and merges.
- Polygon lasso selection (`selection_select_polygon`).
- Retouch strokes: clone stamp, dodge, burn, sponge, smudge (`src/retouch.h`).
- Text rendering: baked bitmap font with per-glyph advances, scaling, newlines (`src/font.h`).
- Responsive workspace: arbitrary document sizes, resizable window, Clay-driven layout (`src/ui_shell.c`) painted by the in-house SDF renderer (`src/ui_sdf.c`), GPU presentation via SDL with software fallback.
- Navigation: zoom to fit, wheel zoom about the cursor, middle-drag pan, `0` to refit.
- SDL desktop shell with a compact Photoshop-style workspace: menu strip, options bar, left tools, center document, right panels, and bottom status/options area.
- C API in `src/openshop_api.h` and matching JavaScript facade in `js/openshop-api.mjs`.
- Visual QA screenshots generated by `make visualbench` into gitignored `visualbench/`.

## Feature Parity Targets

- Selection tools: freehand lasso gesture in the shell (marquee, wand, polygon lasso via APIs, feather, select all/deselect/invert shipped).
- Navigation tools: move tool, keyboard zoom presets/actual pixels (wheel zoom, pan, fit-to-screen shipped).
- Brush system: pressure-ready brush model, custom tips, brush preset save/load (hardness, spacing, scatter, flow shipped in `src/brush_engine.h`).
- Pixel editing: healing brush (clone stamp, smudge, dodge, burn, sponge, crop, canvas/image resize, blur, sharpen shipped).
- Layers: groups, adjustment layers, smart-object-like embedded documents (blend modes, masks, clipping masks shipped).
- Text and vectors: editable text layers, path editing, vector shapes, stroke/fill properties (rasterized text stamping shipped).
- Color: foreground/background swatches, swap/default colors, color picker, pattern fill (gradients shipped).
- Files: layered PSD records, PNG/JPEG/TIFF baseline, autosave/recovery, recent files (flattened PSD export + raw/RLE import shipped).
- Automation: stable C command ABI, JavaScript command facade, batch command execution, scriptable document/layer/tool state.
- UI: keyboard shortcut editor, panel docking, clickable tool rail and layer rows (responsive Clay+SDF shell, contextual options bar, compact mode shipped).
